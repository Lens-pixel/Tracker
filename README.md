# Calorie Bot — Telegram-бот учёта КБЖУ по фото, голосу и тексту

MVP Telegram-бота для учёта калорий и БЖУ на базе **aiogram 3**, **SQLite** и **Gemini Flash**.

## Возможности
- **Публичная оферта и отказ от медицинской ответственности:** обязательное принятие условий до старта (с фиксацией времени в БД) + команда `/terms` и кнопка `📄 Публичная оферта`.
- **Онбординг за 30 секунд:** пол, возраст, рост, вес, активность, цель → расчёт дневной нормы КБЖУ.
- **Учёт еды по фото, голосовому и тексту** + уточнение порций (`✅ Записать`, `✏️ Уточнить`, `🗑 Отмена`).
- **Сводки:** `📊 Сегодня` (с удалением последней записи) и `📈 Неделя`.
- **Два способа оплаты подписки:**
  - **Telegram Stars** (мгновенная автоматическая активация);
  - **Kaspi (тенге)** — пользователь присылает PDF/скрин чека, админу в Telegram приходит заявка с кнопками `✅ Одобрить` / `❌ Отклонить`.
- **Админ-статистика:** `/stats`.

## Что заполнить в `.env` перед запуском в продакшен
- `KASPI_PAY_URL` — ссылка на оплату Kaspi Pay (если есть) и/или `KASPI_PHONE` + `KASPI_RECIPIENT` (ФИО/ИП).
- `KASPI_PRICE_1M_KZT` / `KASPI_PRICE_3M_KZT` — цены в тенге.
- `SUPPORT_CONTACT` — ваш Telegram-аккаунт поддержки для оферты.
- `ADMIN_IDS` — ваш Telegram ID (узнайте его, отправив `/stats` боту), чтобы получать чеки Kaspi на подтверждение.

## Запуск локально (Windows / PowerShell)

```powershell
.\.venv\Scripts\python.exe bot.py
```

Либо двойным кликом по `start.bat`.

## Деплой на Render.com (Free Web Service)

1. Загрузите проект в **приватный** репозиторий GitHub (`.env` и `*.db` уже добавлены в `.gitignore`).
2. На [render.com](https://render.com) нажмите **New + → Web Service** (или **Blueprint**, чтобы подтянулся `render.yaml`) и выберите репозиторий.
3. Настройки (если создаёте Web Service вручную):
   - **Runtime:** Python 3 (`PYTHON_VERSION=3.12.8`)
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Health Check Path:** `/health`
4. В разделе **Environment Variables** добавьте переменные из `.env` (`BOT_TOKEN`, `GEMINI_API_KEY`, `KASPI_PHONE`, `SUPPORT_CONTACT`, `ADMIN_IDS` и др.).
   `RENDER_EXTERNAL_URL` и `PORT` Render задаст сам — бот автоматически переключится в режим **Webhook** и будет просыпаться при каждом сообщении от пользователей.
5. **Важно:** остановите локальную копию бота на ПК, чтобы не было конфликта с Render.

> ✅ **Постоянная бесплатная база на Render (Neon.tech):**
> 1. Зарегистрируйтесь на [neon.tech](https://neon.tech) → создайте бесплатный проект → скопируйте **Connection string** (`postgresql://...`).
> 2. Добавьте её в Render → **Environment Variables** как `DATABASE_URL`.
> Бот сам создаст все таблицы в PostgreSQL при первом запуске, и данные пользователей/подписок больше никогда не пропадут при перезапусках. Локально без `DATABASE_URL` бот продолжает использовать SQLite.
